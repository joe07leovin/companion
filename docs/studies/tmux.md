## Commands (what each does)
- tmux ls : lists all active sessions 
- tmux: starts a new unamed session 
- tmux attach: attaches to the unnamed session
- tmux new -s <name>: starts a new named session 
- tmux attach -t <name> switches to named session 
- cntrl+b -> d: switches to ssh from tmux session
